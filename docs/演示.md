# 演示

这个板块先占位，等浏览器实时演示的素材整理好之后再填。

## 计划放什么

- 一段录屏或动图：选视频 → 点「连接」→ 播放 → 检测框实时叠加在画面上
- 右侧延迟面板的截图：`Total`、`Gateway`、`gRPC`、`Infer`、`Objects`、`In flight`
- 一段说明：从浏览器抽帧到结果回填，中间经过哪几跳、每跳大概多少时间

## 想自己先跑一遍

浏览器演示的完整步骤在 [启动指南](启动指南.md)，仓库自带了测试视频
`testdata/test.mp4`（H.264，640x480）。要跑起来需要同时开着两个进程：

```bash
# 终端 1：推理节点
cd python_ai && python -u Pserver.py

# 终端 2：网关
cd build && ./server 127.0.0.1:50051

# 然后用浏览器打开 web_demo/index.html，点「连接」→ 选 testdata/test.mp4 → 「播放」
```
