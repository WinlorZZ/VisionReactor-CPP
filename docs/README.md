# 文档索引

本目录是 VisionReactor-CPP（`slim` 分支）的全部文档。原则：按实际代码写，不描述代码里没有的东西。

第一次接触这个项目，按这三步走：

1. [00 开始项目](00-开始项目.md) —— 从 `clone` 到拿到第一个 JSON，约 15 分钟。照抄即可，每步都写了「应该看到什么」，附排错表。
2. [06 动手验证](06-动手验证.md) —— 接着做四个实验：半包、去掉 tie、让推理挂住、持续发帧。
3. [05 带你过一遍](05-带你过一遍.md) —— 系统理解整个项目（全景 → 流程 → 数据链路 → 内存管理 → 取舍 → 自测），约 2–4 小时。

## 手绘设计图说明

`diagrams/` 下两张 `.drawio` 是手绘的，大部分仍与当前代码一致：

`全流程.drawio` — 服务启动流程、一次 TCP 连接的完整处理、`readv` 分散读与 ET 循环读的返回值分支、线程池内部（`workers` 创建 / `cv.wait` / 临界区 / `move` 取任务）。

注意，有一处过时：图上写「回调函数将任务分发给线程池」。当前实现是
[`Server::handleOnMessage`](../src/Server.cpp) 在 EventLoop 线程直接调用 `business()`——
协议解析必须与 socket 读取同线程。

`Class Diagram.drawio` — 第 1 页三层类关系（01 服务器控制层 / 02 网关与异步业务层 / 03 Reactor、协议缓冲与资源层）仍然准确。

注意：第 2 页是 H.264 Annex B 解析子系统，`slim` 分支已移除（`h264_demuxer.*`、
`Connection::processH264Nalus()`、`Buffer::findH264StartCode()` 都不在了）。

保留这两张图的理由：它们记录了设计意图，而上面标注的过时点本身就是项目演进的证据。
